# ESP32 CYD — HID Emulator (пульт)

Плата ESP32-2432S028 как пульт: по Wi-Fi тянет список кнопок с сервера
(`GET /keys`) и шлёт нажатия (`POST /press`). UI на LVGL 8.3.

## Stage 1 (текущее)

Дисплей + тач + LVGL + Wi-Fi + сетка кнопок с сервера + статус-бар
(индикатор Wi-Fi, обновить, настройки).

## Как собрать

1. Открой папку `esp32` в VS Code с расширением PlatformIO.
2. Отредактируй `src/config.h`: Wi-Fi SSID/пароль, адрес сервера, порт, токен.
3. Подключи плату по USB, нажми **Upload**.

Монитор порта: 115200.

## Что может потребовать подстройки (пины/ориентация)

- Если картинка перевёрнута/зеркальна — крути `offset_rotation` (0..3) у панели
  и тача в `src/main.cpp`.
- Если тап попадает не туда — подбери `TOUCH_X_MIN/MAX`, `TOUCH_Y_MIN/MAX`
  в `src/config.h`.
- Если цвета «красно-синие наоборот» — `LV_COLOR_16_SWAP 1` в `src/lv_conf.h`.
